Ты делаешь страницу уровня хорошей студии, а не «учебный пример». Следуй этим правилам.

## 1. Сначала система, потом разметка
В `:root` объяви токены и используй ТОЛЬКО их:
- цвета: `--bg`, `--surface`, `--ink` (текст), `--muted`, `--brand`, `--brand-2` (акцент), `--line`; 1 основной + 1 акцентный + нейтрали. Не больше 2 ярких цветов.
- шкала отступов: 4·8·12·16·24·32·48·64·96·128 (px). Секции: `padding-block: clamp(64px, 9vw, 128px)`.
- радиусы: `--r-sm:10px; --r-md:16px; --r-lg:28px`; тени в 2 уровня (мягкая и «поднятая»), с цветом фона, а не чисто чёрные: `0 10px 30px -12px rgb(60 30 60 / .25)`.
- шрифты: системный стек или 1 гарнитура; заголовки жирнее и плотнее.

## 2. Типографика
- `h1: clamp(2.4rem, 6vw, 4.5rem); line-height:1.05; letter-spacing:-.02em`, `h2: clamp(1.8rem, 4vw, 3rem); line-height:1.12`.
- Основной текст 16–18px, `line-height:1.6`, ширина строки ≤ 65 символов (`max-width: 60ch`).
- Контраст текста ≥ 4.5:1. Серый текст только `--muted` на светлом фоне, не светлее #6b6b76.
- Над заголовком — «eyebrow» (мелкий капс с трекингом), под ним — подзаголовок в `--muted`.

## 3. Композиция и ритм
- Контейнер `width:min(1120px, 100% - 40px); margin-inline:auto`.
- Чередуй фоны секций (bg / surface / тёмная / градиентная), между ними — волна или скос, а не голая линия.
- Hero: 2 колонки (текст слева, визуал справа), один главный CTA + один вторичный, под ними «доказательство» (3 цифры или логотипы). Визуал — многослойный: крупные размытые градиентные пятна позади, основной объект, 2–3 плавающих декоративных элемента.
- Сетки через `display:grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); gap: 24px`. Никаких «стен» из одинаковых блоков: варьируй размер (одна карточка крупнее), добавь номера 01/02/03, иконки, крупные цифры.
- Шапка: логотип · 3–4 ссылки · кнопка-CTA справа; `position:sticky` с `backdrop-filter: blur(10px)` и полупрозрачным фоном; на мобильном — бургер.
- Футер: 3–4 колонки, тёмный фон, нижняя строка с годом.

## 4. Живость (умеренно)
- Hover у каждой кликабельной вещи: подъём `translateY(-4px)` + тень, `transition: .25s cubic-bezier(.2,.8,.2,1)`.
- Появление при скролле: `IntersectionObserver` добавляет `.in` (opacity/translate), и всегда есть запасной вариант без JS (`.no-js .reveal{opacity:1}` либо показывай по умолчанию, а скрывай только при наличии JS).
- `@media (prefers-reduced-motion: reduce)` отключает все анимации.
- Фокус: видимое кольцо `:focus-visible { outline: 3px solid var(--brand-2); outline-offset: 2px }`.

## 5. Компоненты — рецепты
Кнопка: `padding:.85em 1.5em; border-radius:999px; font-weight:700; background:var(--brand); color:#fff; box-shadow: 0 8px 20px -8px var(--brand)`; `:active{transform:translateY(1px)}`. Вторичная — прозрачная с рамкой 2px.
Карточка: `background:var(--surface); border-radius:var(--r-lg); padding:28px; box-shadow: var(--shadow)`; внутри: иконка в круге 56px → заголовок → текст → ссылка/кнопка.
Форма подписки: поле и кнопка в одной «плашке» (flex, `border-radius:999px`, белый фон), поле с `label` (можно visually-hidden), ошибка под полем `role="alert"`.
Успех формы: блок успеха — **СОСЕД формы, а не её потомок**: `<form id="f">…</form><div id="ok" hidden>…</div>`; при успехе `form.hidden = true; ok.hidden = false`. Если поместить сообщение внутрь скрываемой формы, его никто не увидит.
Обязательно: нет `alert()`, кнопки — `<button>`, картинки/иконки — inline SVG или эмодзи (внешних файлов и CDN нет, страница открывается двойным кликом).

## 6. Адаптив
Mobile-first. На 375px: нет горизонтальной прокрутки (проверь!), колонки в одну, кнопки на всю ширину, `padding-inline:20px`, шрифты через `clamp`. Бургер-меню с `aria-expanded`.

## 7. Частые провалы (не делай)
- Нет CTA в шапке; нет второго слоя в hero; все секции одного цвета.
- Данные «под капотом» не выведены: у карточки есть поля (возраст, порода, цена), а на экране их нет. Всё, что описано в концепте/данных, должно быть видно.
- Текст на пастельном фоне светло-серым. Заголовки без `line-height`. Огромные пустоты (>160px) между блоками.
- Скрытый `hidden`-элемент, который должен появиться, лежит внутри скрытого родителя.
- Заявлять «готово», не открыв страницу. Смотри навык verify-ui.

## 8. Порядок работы
1. Прочитай концепт/образец и текущие файлы. 2. Запиши токены и каркас. 3. Файл >300 строк пиши частями (write_file + append_file). 4. Открой результат через preview_page, сценарии — через run_in_page. 5. Исправь найденное и проверь снова. 6. В ИТОГе перечисли только то, что реально подтвердили инструменты.
