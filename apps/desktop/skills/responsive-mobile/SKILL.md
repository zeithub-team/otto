Сначала телефон, потом расширяй. Страница обязана работать на 375, 768 и 1280 px.

## Основа
- `<meta name="viewport" content="width=device-width, initial-scale=1">` — всегда.
- **Mobile-first:** базовые стили для узкого экрана, дальше `@media (min-width: 768px)` и `(min-width: 1100px)`. Брейкпоинты по содержимому, а не по устройствам.
- Единицы: `rem`/`em`, `%`, `clamp()`, `min()`, `max()`; фиксированные `px` только для границ и мелочей. Шрифты и отступы через `clamp(a, b vw, c)`.
- Контейнер: `width: min(1120px, 100% - 40px); margin-inline: auto`.

## Раскладка
- Колонки: `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))` — сами перестроятся; на телефоне — одна колонка.
- Flex с `flex-wrap: wrap` и `gap`; длинные слова — `overflow-wrap: anywhere`; в flex/grid детям `min-width: 0`, иначе распирают страницу.
- Картинки и видео: `max-width: 100%; height: auto`; фиксированные ширины в блоках — источник горизонтальной прокрутки.
- Таблицы: оберни в контейнер с `overflow-x: auto` или перестрой в карточки.

## Тач и мобильный UX
- Цель касания ≥ 44×44 px, расстояние между целями ≥ 8 px; `:hover` не единственный способ что-то показать.
- Кнопки главных действий на мобильном — на всю ширину; меню — бургер с `aria-expanded`, закрывается по клику вне и по Esc.
- Поля: правильный `type` и `inputmode` (email, tel, number), `autocomplete`; шрифт полей ≥ 16 px (иначе iOS увеличивает страницу).
- Фиксированные шапки/подвалы не должны съедать больше ~15% высоты; учитывай `env(safe-area-inset-*)`.
- `100vh` на мобильном обманывает — используй `100dvh` или `min-height`.

## Проверка (обязательно)
1. `preview_page` — сообщит о горизонтальной прокрутке на 375 px.
2. `run_in_page` c `width: 375`: бургер открывается, форма отправляется, ничего не обрезано:
```
return { overflowX: document.documentElement.scrollWidth > innerWidth,
         wide: $$('*').filter(e => e.getBoundingClientRect().right > innerWidth + 1).slice(0, 5).map(e => e.tagName + '.' + e.className) };
```
3. Повтори на 768 и 1280. Список «wide» пуст — готово; иначе найди виновника и исправь.

## Частые провалы
`width: 100vw` (даёт полосу прокрутки); блоки с `min-width` больше экрана; текст в 12 px на телефоне; кнопки в ряд, не влезающие; hover-меню, недоступное на тач-экране; картинки без `max-width`.
