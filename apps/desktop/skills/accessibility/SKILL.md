Интерфейс должен работать без мыши, без зрения и при плохом контрасте. Цель — WCAG 2.1 AA.

## 1. Семантика
- Настоящие элементы: `<button>` для действий, `<a href>` для переходов, `<nav>`, `<main>`, `<header>`, `<footer>`, `<h1>…<h3>` по порядку без пропусков. Один `<h1>` на страницу.
- Нельзя `div onclick`: он не фокусируется и не читается. Если иначе никак — `role`, `tabindex="0"` и обработка Enter/Space.
- `<html lang="…">` обязателен; у страницы есть `<title>`.

## 2. Контраст и цвет
- Обычный текст ≥ 4.5:1, крупный (≥18px или 14px bold) и элементы UI ≥ 3:1. Проверяй серый текст на светлом и цветной на цветном.
- Смысл не только цветом: ошибка = цвет + иконка/текст; ссылки в тексте подчёркнуты.

## 3. Клавиатура и фокус
- Всё, что кликается, достижимо Tab и работает по Enter/Space; порядок Tab совпадает с визуальным.
- Видимый фокус всегда: `:focus-visible { outline: 3px solid …; outline-offset: 2px }`. Никогда `outline: none` без замены.
- Модальные окна: фокус внутрь при открытии, ловушка фокуса, Esc закрывает, фокус возвращается на кнопку-источник.
- Ссылка «Перейти к содержимому» первым элементом, если шапка длинная.

## 4. Формы
- Каждому полю `<label for>` (можно визуально скрытый); подсказки и ошибки связаны через `aria-describedby`; невалидное поле `aria-invalid="true"`.
- Ошибки объявляются: `role="alert"` или `aria-live="polite"`; фокус переводится на первое поле с ошибкой.
- Не полагайся на placeholder как на подпись.

## 5. Изображения, иконки, медиа
- `<img alt="…">` осмысленный; декоративные — `alt=""`; иконка-кнопка — `aria-label`.
- Видео/анимации: можно остановить; `@media (prefers-reduced-motion: reduce)` отключает движение.

## 6. Размеры и масштаб
- Цель касания ≥ 44×44 px. Текст масштабируется до 200% без потери содержимого; шрифт в rem/em, не в px для основного текста.
- `meta viewport` без `user-scalable=no`.

## 7. Динамика
- Раскрывашки/меню: `aria-expanded` и `aria-controls` синхронны с состоянием.
- Вкладки/аккордеоны — по паттернам ARIA, стрелки для навигации внутри виджета.

## 8. Проверка в браузере
Через run_in_page проверь: у каждого `img` есть `alt`; нет `button` без текста/aria-label; у всех `input` есть label; порядок заголовков; `document.documentElement.lang`; фокусируемость элементов (`el.tabIndex >= 0`). Пример:
```
return {
  imgsNoAlt: $$('img:not([alt])').length,
  btnsNoName: $$('button').filter(b => !(b.textContent.trim() || b.getAttribute('aria-label'))).length,
  inputsNoLabel: $$('input:not([type=hidden])').filter(i => !i.labels?.length && !i.getAttribute('aria-label')).length,
  h1: $$('h1').length, lang: document.documentElement.lang
};
```
Всё, что вернулось не нулём, — исправь и проверь снова.
